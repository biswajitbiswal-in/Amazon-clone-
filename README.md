# 🛒 Amazon Clone

A simple **Amazon homepage clone** built using HTML and CSS for learning and practice purposes.

🔗 **Live Demo:** [amazon-clone-huwc.vercel.app](https://amazon-clone-huwc.vercel.app/)

---

## 📖 About

This project recreates the look and feel of the Amazon homepage as a front-end practice exercise. It focuses on structuring a real-world layout using semantic HTML and styling it with CSS — a great starting point for anyone learning how large e-commerce sites are put together.

## ✨ Features

- 🧭 Responsive-style Navbar
- 📦 Product sections with grid/card layout
- 🔻 Footer with site links

## 🛠️ Technologies Used

- **HTML** – Page structure and content
- **CSS** – Styling and layout

## 🚀 How to Use

**Option 1: View it live**
Just visit the deployed site: [amazon-clone-huwc.vercel.app](https://amazon-clone-huwc.vercel.app/)

**Option 2: Run it locally**

```bash
# Clone the repository
git clone https://github.com/<your-username>/amazon-clone.git

# Navigate into the project folder
cd amazon-clone

# Open index.html in your browser
```

Simply double-click `index.html`, or open it directly in any web browser — no build tools or dependencies required.
